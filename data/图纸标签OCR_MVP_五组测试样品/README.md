# 图纸-标签 OCR MVP 五组测试样品

本数据集为模拟数据，用于验证以下流程：

1. 读取 PDF 图纸文字；
2. 对标签图片执行 OCR；
3. 提取产品名称、型号、电压、功率、版本号和序列号；
4. 将图纸值与标签值逐字段比对；
5. 输出 PASS / FAIL 及异常说明。

## 样本说明

- sample_001：完全一致，预期 PASS
- sample_002：额定电压数字错误，预期 FAIL
- sample_003：英文型号拼写错误，预期 FAIL
- sample_004：额定功率单位错误，预期 FAIL
- sample_005：版本号字段缺失，预期 FAIL

每个样本目录包含：

- drawing.pdf：模拟工程图纸
- label.png：模拟产品标签照片
- ground_truth.xlsx：人工标准答案

注意：所有产品和参数均为虚构，仅用于软件开发测试。
